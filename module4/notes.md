# Module 4 Notes: Git and GitHub Workflow

In this module, I learned how Git records a project's history through focused
commits and meaningful commit messages. I also practiced using branches to keep
new work separate from the stable `main` branch.

GitHub adds collaboration to that workflow. A pull request makes it possible to
review the files and describe a change before merging it into `main`. After a
merge, pulling the latest `main` branch keeps the local repository synchronized
with GitHub.
