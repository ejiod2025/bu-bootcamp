# BU CS Foundations Bootcamp

This repository contains my work for the Boston University Online AI Programs
CS Foundations Bootcamp. It documents my progress from introductory Java
programs through data structures and Git-based development workflows.

## Structure

- `module1/` - Development environment setup and first Java programs
- `module2/` - Programming fundamentals, methods, file input, and file output
- `module3/` - Classes, collections, lookups, and sorting
- `module4/` - Notes about Git, GitHub, branches, and pull requests

## Programs

Each module folder contains the source files and test data used for that
module's activity. The commit history records each activity separately so the
development process is easy to follow.
